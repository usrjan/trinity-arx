# TrinityARX - Конфигурационный файл

## trinity_config.json

Этот файл содержит настройки подключения к базе данных и параметры плагина.
**Важно:** Файл должен находиться в той же директории, что и скомпилированный модуль (.arx).

### Структура файла:

```json
{
  "database": {
    "host": "IP-адрес или имя сервера MySQL",
    "user": "имя пользователя БД",
    "password": "пароль пользователя БД",
    "name": "имя базы данных"
  },
  "paths": {
    "base": "путь к базовой директории для DWG файлов"
  },
  "settings": {
    "timer_interval_ms": интервал таймера в миллисекундах (число),
    "logging_enabled": true/false (включить логирование)
  }
}
```

### Пример конфигурации:

```json
{
  "database": {
    "host": "10.250.11.112",
    "user": "webdev",
    "password": "YOUR_PASSWORD_HERE",
    "name": "trinity_core"
  },
  "paths": {
    "base": "D:\\\\trinity"
  },
  "settings": {
    "timer_interval_ms": 5000,
    "logging_enabled": true
  }
}
```

### Примечания по безопасности:

1. **Не коммитьте этот файл в репозиторий** с реальными паролями
2. Создайте файл `trinity_config.json` локально на каждой машине
3. Используйте `.gitignore` для исключения этого файла из контроля версий
4. При изменении пароля обновите только этот файл (перекомпиляция не требуется)

### Настройка прав доступа к файлу (Windows):

Для дополнительной защиты установите права только на чтение для пользователя:
```cmd
icacls trinity_config.json /grant %USERNAME%:R
```
