# Тестирование динамического щита

## Команда для создания тестового щита

После загрузки плагина в AutoCAD выполните команду:

```
TEST_SHIELD
```

или

```
TRINITY_TEST_SHIELD
```

## Что происходит при выполнении команды:

1. **Создается блок** с именем `TEST_SHIELD_2000x500`
   - Длина: 2000 мм
   - Ширина: 500 мм
   - Толщина: 40 мм
   - 2 отверстия диаметром 20 мм

2. **Блок вставляется** в начало координат (0,0,0)

3. **Слои создаются автоматически**:
   - `TRINITY_SHIELDS` - контур щита
   - `TRINITY_HOLES` - отверстия

## Как проверить работу:

1. Загрузите ARX-файл в AutoCAD 2026:
   ```
   APPLOAD
   ```

2. Введите команду:
   ```
   TEST_SHIELD
   ```

3. Выберите созданный объект

4. Откройте палитру свойств (**Ctrl+1**)

5. Посмотрите доступные параметры блока

## Ограничения текущей версии:

- Блок создается как статический (без динамических параметров растягивания)
- Для изменения размеров нужно пересоздать блок с новыми параметрами
- Динамические свойства можно добавить вручную через редактор блоков (**BEDIT**)

## Следующие шаги:

Для полноценных динамических блоков потребуется:
1. Использовать `AcDbDynBlockReferenceProperty` для создания параметров
2. Добавить `AcDbStretchAction` для действия растягивания
3. Настроить связи между параметрами и геометрией
